  A cross-platform app that turns places discovered online into plans to visit. I work across its Spring Boot API and worker, Terraform-based AWS infrastructure, CI runners, deployment workflows, and observability.

- **[CMC](https://github.com/boostcampwm2025/web02-CMC)** · Real-time code review platform  
  I built backend features, [GitHub Actions CI/CD](https://github.com/boostcampwm2025/web02-CMC/pull/164), [Prometheus/Grafana monitoring](https://github.com/boostcampwm2025/web02-CMC/pull/208), and [Terraform-based cloud infrastructure](https://github.com/boostcampwm2025/web02-CMC/pull/463).

- **Colab Recommend**  
  I designed and built a Spring Boot system for research equipment recommendations and inquiry support. It combines catalog-grounded RAG with exact, keyword, and vector search, presents evidence for product candidates, and provides an operator workbench for uncertain matches and quote requests.
